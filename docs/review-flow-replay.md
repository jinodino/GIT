# 코드 리뷰 실행 흐름 재생

PR에서 AI 리뷰 워크플로가 실행되면 `review-flow.html`을 기록합니다. GitHub의 **Actions → AI Code Review → 해당 실행 → Artifacts**에서 `review-flow-pr-<PR 번호>`를 내려받아 압축을 풀고 HTML 파일을 브라우저로 열면 됩니다. 재생은 자동으로 시작하며, 이전·다음 단계와 속도를 조절할 수 있습니다.

화면에는 PR 이벤트, 변경 파일 선별, 리뷰 프롬프트, LLM의 도구 호출, 도구 결과 요약, 리뷰 초안, 자기 비판, 수정된 리뷰, 최종 리뷰, PR 댓글과 수정 제안 게시 시도가 순서대로 표시됩니다. 각 단계에서 출발점과 도착점, 입력값, 처리 내용, 출력값을 볼 수 있습니다. 값은 해당 GitHub Actions 실행에서 수집한 것이며, HTML을 연 뒤 GitHub나 OpenAI에 다시 요청하지 않습니다.

도구 결과 원문 전체는 저장하지 않습니다. 파일 읽기는 줄 수와 문자 수, 코드 검색은 결과 개수와 위치, Ruff는 진단 개수와 코드를 기록합니다. 프롬프트·LLM의 리뷰 내용·자기 비판은 최대 2,400자까지 보관하고 흔한 API 토큰 형식은 가립니다. 따라서 내려받은 HTML에 공개하면 안 되는 코드나 리뷰 내용이 포함될 수 있는지 확인한 뒤 공유하세요. GitHub Actions 아티팩트의 보관 기간은 7일입니다.

워크플로는 보안을 위해 PR의 **base 커밋에서 에이전트 코드를 설치**합니다. 이 기능이 들어 있는 PR을 열었을 때는 아직 base에 재생 코드가 없으므로 그 PR 실행에서 아티팩트가 생성되지 않습니다. 기능을 base 브랜치에 반영한 뒤 새 PR을 열거나 기존 PR에 새 커밋을 push하면 재생 기록이 생성됩니다.
